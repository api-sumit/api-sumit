## 🚀 Featured projects

### 📚 [Padhopedia](https://padhopedia.com)
A learning platform that connects teachers and students. Teachers share documents and video lessons, and students take exams online or in print. File storage runs on a hard-capped free tier, so costs cannot grow unexpectedly.
<br>**Stack:** React, Vite, Supabase (Postgres, Auth, Edge Functions), Backblaze B2

### 🃏 [Flip Seven Online](https://flip-seven-ashy.vercel.app/)
A browser-based multiplayer table for a push-your-luck card game, built to play with friends. It has a fully tested rules engine, host controls enforced on the server, and Redis-backed game state that stays consistent across serverless instances.
<br>**Stack:** Next.js, React, Tailwind CSS, Upstash Redis, Vercel

### 💬 Chattr
A real-time lobby chat app with Socket.IO signaling, structured so peer-to-peer audio and video can be added next.
<br>**Stack:** Next.js, Node.js, Express, Socket.IO

### 🛡️ Bot Traffic Scorer
A Python tool that scores web sessions as valid, suspicious, or bot, using request velocity, impossible behavior, user agent, and geofencing checks.
<br>**Stack:** Python
